# 黑龙 Fatalis（em013_00）AI 解析

> 交互版（出招模拟器、扇区热力图、带中文注释的 THK 代码）：<https://mhwi.helsincy.com>（或本地打开 `web/index.html`）。
> 本文所有概率都由 `scripts/sim.js` 对 THK 全部随机分支做**精确枚举**得出，可用下文命令复现。
> 分析对象是**《传说中的黑龙》**（q66845，可重复接取）。特别任务《黑龙》（q51612，5 次力尽、只能打一次）与它数值相同，只多几段该任务专属的分支，见 7.1 节。

## 1. 数据来源与方法

| 步骤 | 工具 | 说明 |
|---|---|---|
| 解包 | `tools/mhw_chunk.py` | 移植自 MHWNoChunk 的命令行版：Oodle 解压 + 16 字节 XOR 解密，合并 chunkG0~G60 |
| 反编译 | `tools/decompile.py` → Leviathon | `em013.thklst` + 18 个 `.thk` → `data/em013_00/*.nack` |
| 结构化 | `tools/nack2json.py` | nack → JSON AST；`scripts/check.js` 逐行往返校验（5550 段 / 587 个 if / 670 个随机块全部一致，随机权重和均为 100） |
| 求值 | `web/js/thk-core.js` | 按 Leviathon 规范的执行语义解释 THK，对随机分支深度优先全枚举，得到精确概率 |

**关于「官方招式名」**：游戏文本（`em_info_chS.gmd` 猎人笔记等）只有怪物简介与攻略提示，**没有面向玩家的招式名**。唯一的官方命名是写在 `MonsterHunterWorld.exe` 里的内部动作名（例如 `L2_SPECIAL_WIDE_RANGE_FIRE_SHOOT` = 扇形火），本文和网页都同时给出内部名、逐词直译和社区俗称。

**记号约定**（THK 的比较方式已在 exe 中核对，见 `0x1413346a0` 条件分发）：

- 距离：`distance_*().leq(N)` 是 ≤N（含 N），`.gt(N)` 是 >N（不含 N）。文中「≤1000」「>5000」照此理解；「>1000 且 ≤5000」表示两档之间——THK 按 ≤A、≤B 依次判断，所以区间都是左开右闭。垂直距离同样是 ≤ / >（取绝对值）。
- 角度：从正面顺时针计；`angle_2d_cw_between(a,b)` 两端都含（`0x14132bb00`），跨 0° 时为 ≥a 或 ≤b。
- 血量：`hp_percent().leq(N)` 先算 当前 ÷ 最大 × 100，再**截断取整**（`cvttss2si`）后与 N 比较。所以「HP≤49%」即实际血量 <50%，「HP>75%」即实际 ≥76%。按目标血量判断的函数（如 `103/10E/113(3,N)`）也是取整后的整数比较（`0x141338ee0`）。
- 计数器：整数比较，按文中写的符号。

一轮决策从 `em013_00.node_000` 开始，选出一招后 `reset` 回到入口重新判定：

```
node_000
 ├─ G142  清零骑乘计数 R12
 ├─ 001   丢失目标 / 烟雾弹 (5D)
 ├─ 027   10A 抓着猎人（三阶段，走抓握攻击表）
 ├─ 014   一二阶段血量：HP≤77% 1转2，HP≤49% 2转3
 ├─ 017   三阶段血量：HP≤40/25/5% 各一次终极大招
 ├─ 002   起飞/降落计数（双翼破坏则不飞）
 ├─ 035   一阶段瓦砾
 ├─ target(3/4) → 006；target(55) 钩爪 → G004 反钩爪
 ├─ flying → 008 飞行攻击 AI
 └─ else   → 009 地面攻击 AI
            高台(041/051) → 112(022) → 110(2)(018) → 转姿态计数(010)
            → 一阶段额外车(015) → 目标是随从猫 2D(1)(157) → 5% 捕食(016) → 遮挡(038) → 对空(019)
            → 主攻击表：姿态 × 阶段 × 距离（063~108）

```

**连段的本质**：地毯→扇火、大拍→扇火、受击追加等都发生在攻击节点内部，所以连段之间**不会**重新做烟雾、血量、钩爪、高台检测。

## 4. 关键结论

1. **距离决定查哪张表，角度只挪动表内权重。** 侧面的侧面地毯、背后的甩尾只占 20~30%，任何角度都可能出正面招。
2. **扇火的三个来源**：主表直接扇火（一阶段头前 20%）；正面地毯**必接**扇火、大拍/吐痰/孕吐 **35%** 接扇火（都需要目标在前方半圈（偏离正面 ≤90°）且距离 >800）；受击追加表。开局 `10E()` 期间（发现目标后前 5 次 AI 出招，见第 7 节）所有扇火节点改为随机出单火球/三连/地毯/直线火。
3. **一阶段转四足是 10%**（xlsx 正确，B 站正文写的 15% 与代码不符）。
4. **一阶段从不吐痰**（主表里吐痰权重全为 0），二阶段起吐痰最高 50%。
5. **一阶段四足贴脸（≤500）正面/背后有 10% 只后退不攻击**，这一轮以后退结束。
6. **三阶段二足的 5% 捕食判定排在主表之前**，因此三阶段二足所有招式概率都是二阶段同表的 0.95 倍。
7. **受击追加（追击）50% 在三个阶段都生效**（判断排在阶段判断之前）；二阶段/三阶段另有 `113(3,40)`（exe：目标猎人当前血量 ≤ 最大血量的 40%）时 30%/50%。
8. **高台横扫火「7 招必出」是死代码**。
9. **《传说中的黑龙》走默认 AI。** 特别任务《黑龙》（q51612）的 6 处专属分支实际生效都要 `108()` / `109()` 为真，而它们在 exe 里本身就要求任务号 == 51612：开场把目标设为事件点出 G139；NPC 事件窗口内一阶段保持二足（7.1 节）。
10. **遮挡 `10D()`**：二足 >900 且 ≤6000 / 四足 >1500 且 ≤6000 时进入遮挡 AI，大概率出车。
11. **高台判定看脚下地面的属性，不看高度**：`104()` / `104(1)` 读猎人身上一个状态位，该位每帧由猎人正下方碰撞面的属性决定（每帧竖直向下打射线，人在空中也看正下方，见 7.4 节），所以击龙枪那一格的网子外沿算地面（实测确认）。高台 AI 里没有 Z 字火（S 火）、俯冲、孕吐。「哪块地面算高台」由地图碰撞数据（`sCollision`、地形文件）决定，不在 THK 里，所以**模拟器只把「在高台」当输入**（`104()` / `104(1)` 开关），站立位置本身不参与选招：问题 1、问题 3 的复算就是把这个开关的两种取值全部枚举（见结论 12 的表）。同理一阶段 `102(3)`（瓦砾区）也是开关。
12. **降落被打断后计数已清零。** 所有降落节点（`55.node_017/018/019/123/124`）都先清零飞行计数 R4 再执行落地动作；飞行中每轮先 R4+1，≥3 才可能降落（15%），≥7 必降。所以落地被硬直打断、黑龙仍在空中时，至少再飞 2 轮、平均 4.7 轮，期间不在高台的猎人每轮有 Z 字火（≤1000 20%，>1000 且 ≤5000 二阶段 35% / 三阶段 40%），可以反复打断落地引 Z 字火。打断后留不留在空中看受击表 `em013.em_dmg`：空中的普通部位硬直（第 1~11 条，头部 `FLY_DAMAGE_HIGH`、其他 `FLY_DAMAGE_LOW`）留在空中，倒地、麻痹、睡眠、拘束、击龙枪、钩爪等在空中全部是 `FLY_SWITCH_L4_*`，会掉下来。降落途中被打走哪一列也已在 exe 中确认（见 7.4 节）：选列看离地状态 `+0x1128`，降落的下降段一直持续到**身体接地**、期间每帧续飞行，接地后的着地动作与落地收尾不续、回落为地面；所以落到地面之前打出普通硬直走 `FLY_DAMAGE_*`（飞行动作，继续续飞），黑龙留在空中。下表是不需要先出招就落地的情况：

| 情况 | 节点 | 结果 |
|---|---|---|
| 二阶段 HP≤49%（等待转三阶段），或一阶段飞行 | `00.node_014` / `00.node_003` | 每个飞行回合一开始就降落：不在高台 → 俯冲落地；在高台 → 二足降落 |
| 二三阶段猎人在高台、水平距离 ≤1000 | `00.node_052` | 直接二足降落（与 R4 无关）；>1000 时 30% 单火球后降落 |
| 两翼都已破坏 | `00.node_002` | 每个飞行回合直接降落 |
| 烟雾弹 / 丢失目标（`5D()`） | `00.node_001` → `00.node_007` | 排在血量检查之前：普通降落 → 索敌，同一轮接着走地面 AI |
| 目标不在场（`target(3/4)`：去了别的区域 / 在黑龙去不了的地方，见 7.2 节） | `00.node_006` | 先普通降落，再移动/索敌 |
| R4 已 ≥3（未被打断的正常飞行） | `00.node_003` | 15% 降落，≥7 必降 |

转阶段检查排在每轮最前面（只有烟雾弹/丢失目标与三阶段 `10A()` 排在它前面），所以 HP 到线时黑龙**不会先在空中出一招**，下一轮直接落地；不在高台时这次落地是「俯冲落地」，它本身带攻击判定，在高台时是不攻击的普通降落。判定针对的是黑龙**当前的目标**（多人时可能不是你）。HP 是在每轮决策时检查的，如果在空中三连火球等连段途中到线，会先打完这一轮。三阶段没有按血量强制降落（终极形态大招只在地面触发，飞行中会延后）。被打断后是否留在空中由动作本身决定，THK 管不到：普通空中硬直（`FLY_DAMAGE_LOW/HIGH`）会留在空中，倒地级硬直（`FLY_SWITCH_L4_DAMAGE_DOWN` 等）会直接掉到地面。

13. **三飞只在三阶段每轮开头、黑龙在地面时检查，跨两档只飞一次。** `00.node_017` 按 HP≤5 / ≤25 / ≤40 的顺序只看最低一档，触发时把更高档的计数一起 +1；飞行中、抓着猎人（`10A()`）、目标不在场（`target(3/4)`）时不检查。所以两次地面检查之间打掉的血（本轮剩下的连段与追击、倒地/麻痹/睡眠/骑乘、整段飞行）跨过几条线都只飞一次——这就是「跳飞」「压三飞」的依据。三飞从地面起手第一帧起全程锁死，起手后打不死。详见 7.2 节。

14. **胸部反击下压是一个只看伤害的独立耐久槽**，不在 THK 里：上限 150 × 部位耐久倍率（单人 10.0）= 1500，打胸部用伤害值扣（破坏值另算），三阶段伤害 ×0.7（等效 ≈2143），打空即反击并回满；而且**只有当前动画开着累计开关时才扣**：四足、飞行、待机、移动、转身、咆哮全程不算，站立的普通攻击才算，其中吐痰、三连蓄力炮、二足左右火、下压、捕食也不算；三飞、转阶段飞行吐息、击龙枪倒地、捕食抓握期间最多扣到剩 1，黑龙在受击反应里或在天上时打空作废。详见 7.3 节。

## 6. 出招概率表

复现单个状态：

```bash
node scripts/sim.js em013_00 phase=1 stance=l2 dist=1500 angle=0          # 一阶段二足头前
node scripts/sim.js em013_00 phase=3 hp=45 stance=l4 dist=400 angle=90    # 三阶段四足胸侧
node scripts/sim.js em013_00 phase=2 hp=60 flying=true dist=2000          # 二阶段飞行
```

## 7. exe 逆向：开局不扇火（`function#10E()`）

社区说法是「开局约 15~20 秒不扇火」（B站九世深渊实测为小地图变红后约 20 秒）。THK 里只能看到这是由 `function#10E()` 控制的，`0x100` 以上的函数是怪物专属的，实现在游戏 exe 里。下面是逆向结果。

### 结论

`function#10E()` **不是计时器**，而是：

```
10E() = 调参表阈值(5) > 开局计数
```

- **阈值 = 5**：写在黑龙专属调参表 `em013.dtt_unq`（类 `nEmDtTune::cEmUniqueEm013`，对象偏移 `+0x17c`），代码默认值是 3，文件覆盖为 5。可用 `python tools/em013_unq.py` 查看。
- **开局计数**（`uEm013` 对象 `+0x20c5c`）：
  - 黑龙**每切换到一个新动作**时 +1，上限 100。
  - **不计数**：新动作在调参表的「不计数列表」里（只有一项：`L2_BIND_VOICE` 二足咆哮）；或者这次切换是**当前动作自己衔接的后续段**（例如车的起手→冲刺→收招、受击硬直等由动作代码直接切换的情况）。THK 选择的动作（包括转身、后退、步行）都会计数。
  - **清零**：怪物发现目标、进入战斗时（`nEmAI::CombatFindBehavior` / `LeadFindBehavior` 开始时）。**例外**：如果此时有猎人与黑龙在同一区域，且仍在黑龙的仇恨列表中（列表项已登记、仇恨值曾达到阈值），就不清零。
- 所以「开局保护」= **发现目标后前 5 次 AI 出招**（咆哮不算）。期间扇火类节点（`G064/068/079/081/088`）都改为随机出单火球/三连/正面地毯/直线火。黑龙一招大约 3 秒，5 招正好对应社区观察到的 15~20 秒。
- 实战推论：转身、后退会消耗计数；**丢烟雾弹后重新索敌不会清零**（猎人一直在同区域、仍在仇恨列表里）；**用回归球离开区域、回来后再被发现会清零**，重新获得 5 次开局保护。这两点与九世深渊的实测一致（[B站 opus/930951641929089095](https://www.bilibili.com/opus/930951641929089095)）。该文从实测得出「开局约 20 秒」，但同文「不拍怒等 5~6 招后开始扇火」的观察正好对应阈值 5。

### 7.2 三飞：跳飞与压三飞

三阶段 HP≤40/25/5% 的三次飞天大招（`55.node_025` → `L2/L4_FINAL_MODE_STAGE_BREATH_START`）在 THK 里的全部触发条件：

1. 只在 Combat_Main 每轮开头检查（`00.node_000` → `00.node_017`）。前面只有烟雾/丢失目标（`00.node_001`：先降落、搜索，同一轮接着检查）和抓着猎人（`00.node_027`，`10A()` 为真时走抓握攻击表并 reset）。
2. 黑龙在天上时整段跳过；目标是 `target(4)` / `target(3)`（目标去了别的区域、在黑龙去不了的地方）时跳过，随后 `00.node_006` 降落并重选目标，下一轮照样检查。
3. HP≤5 且 R9=0 → R7/R8/R9 各 +1；否则 HP≤25 且 R8=0 → R7/R8 各 +1；否则 HP≤40 且 R7=0 → R7 +1。然后出三飞并 reset。计数在出招**之前**就加了，此后不会再清零。
4. 高台（`104(1)`）、钩爪挂在身上（`target(55)`，排在检查之后）都不影响。

由此，「跳飞」「压三飞」能利用的只有一件事：**两次地面检查之间打掉的血，到下一次检查时一次结算**。

| 不检查的窗口 | THK / exe 依据 | 能拖多久 |
|---|---|---|

路线：

- **跳过 40% 那一飞**：从 HP≤49% 触发 2→3 转阶段起，到三阶段第一次地面检查前，把 HP 打到 ≤25%（只出 25% 那一飞，R7 一起置位）。转阶段演出锁死但没有免伤标志，开局飞行段就是社区说的「高台滞空引 Z 火、打断落地」——每次决策时猎人不能站在高台属性的地面上。打到 ≤5% 则只剩一飞，打死则三飞全免（空中动作里血量归零会先往下打射线找落点，场地上空能正常死）。
- **跳过 25% 那一飞**：40% 那一飞收尾落回地面（`FlyFinalModeStageBreathEnd` 构造函数清掉了飞行位），三阶段地面要累计 35 轮才可能再起飞，所以只能在一个地面窗口里从 >25% 打到 ≤5%。
- **压三飞（压最后一飞）**：HP≤5% 之后、下一次地面检查之前打死。追击与倒地/麻痹/睡眠/骑乘是主要窗口；火事场（血量 ≤35%）的玩家天然满足追击条件 `113(3,40)`。三飞起手后全程锁死，起飞瞬间打死不可能。
- **黑龙不会眩晕、也不会疲劳**：实测从未晕过；`em013.dtt_eda`（Blowfish 解密，结构见 MHW-Editor `dtt_eda.bt`）里眩晕与减气的基础值、累积量、上限全为 0，睡眠、麻痹为 300 / 300 / 3000。所以上面的受击窗口里没有眩晕。

### 7.3 胸部反击下压

### 7.4 降落途中的受击与离地状态

黑龙「打断落地留在天上」与「滞空时高台判定」两条社区说法，最后一环都落在 exe 的离地 / 地面状态上，逐环核对如下。

| 环节 | 地址 | exe 中的逻辑 |
|---|---|---|
| 受击选列 | `0x1402c04d0` | 受击编号不在 `0xa3~0xa5` 时：怪物 `+0x1128` 为 1 或 2 → 返回 2（`em_dmg` 空中列），否则 1（地面列）；结果交给 `0x1402be580` 取表 |
| 离地状态是每帧请求制 | `0x141bffd80` | 每帧末：本帧没有任何代码写过 `+0x1128`（脏标志 `+0x1388` 为 0）就回落到默认值 `+0x1258`（地面）；置 1 的是 `0x14033c910`，置 0 的是 `0x1403c2d50` |
| THK `flying()` | `0x14132d2d0` | `+0x1128 == 1` |
| 降落动作 `Em013LandingBase` | 基类 update `0x1415b7ae0` | 状态 0/1（下降动画 `0x1001`）：每帧经 `0x1413943b0` 续飞行，并调用 `0x141cd3750(750)`——已接地（`+0x6f28`）返回真，否则把怪物按 750×帧时间往下移；接地或超时（start 里按 \|离地高度\|/750 + 3 设定）才转状态 2。状态 2（着地动作 `0x1003`/`0x1006`）：`+0x6f28 == 0`（没接地）时才续飞行；状态 3（落地收尾 L2 `0x1005`/`0x1008`、L4 `0x1004`/`0x1007`）：不续 |
| 接地标志 `+0x6f28` | `0x141c0069b` | 地形更新 `0x141bffe30` 每帧按碰撞结果写：接地 1、离地 0；离地时 `+0x14f0` 累加滞空时间 |
| 飞行受击 `FlyDamageLow/High` | 基类构造 `0x141591390` | 给动作 `+0x68` 置 `0x800`（飞行动作）；带这个标志的动作每帧由 `0x1402a7250` 交给运动控制器续飞行 |
| 黑龙动作类里置地面的只有 | — | 空中倒地类受击（`FlySwitchL2/L4Damage*`、`DamageDropBase`，触地时 `0x1415b2070` 显式置 0）、俯冲收尾 `FlySwitchL2AssaultGroundRushEnd`（start 置 0）、`FlyDie`；普通降落不显式置 0，靠每帧回落 |
| 猎人正下方地面 | `0x141c03820` | 从当前位置沿上方向量取头顶 50 到脚下 2000 的竖直线段打射线，命中写入 `+0x10d0` 起的地面信息块（`+0x10f4` 相对高度、`+0x1100` 面编号、`+0x110c` 属性位），未命中重置为默认值 |

结论：

- **降落途中被打**：落到地面之前（下降段一直持续到接地）黑龙处于离地状态，普通部位硬直走空中列 `FLY_DAMAGE_LOW/HIGH`，受击动作本身继续续飞，黑龙留在空中；R4 已在降落节点清零，之后至少再飞 2 轮。接地之后（着地动作、落地收尾）走地面列。
- **滞空时的高台判定**：取正下方的地面，不是最后踩过的地面；高台位不要求着地。向外翻滚后人已在高台范围外，正下方是普通地面，黑龙按普通表出招。
