## 2. AI 文件结构

`em023.thklst`（05）共 72 个槽位，使用 34 个 THK：

| 上下文 | 文件 | 作用 |
|---|---|---|
| Combat_Main | **05/data/em023_00** | **激昂专属战斗主控**，22 个节点 |
| Global | 00/data/em023_55 | 招式库，262 个节点，**与普通金狮子共用** |
| Rage_Enter | em023_07 | 进入愤怒：清零硬化计数 R12，后跃 + 愤怒吼叫 |
| Combat_Critical_HP | em023_20 | 濒死：走向睡眠区域并睡眠（`dying_sleep` 参数激昂个体 90、普通 150，含义未确认） |
| Combat_Turf_War_A/B | em023_23 / em023_50 | 领地争夺 |
| Mount / Combat_Blinded / … | 其余 | 骑乘、闪光、换区等 |

Global 里所有「激昂版」招式都由 `function#D0(5)` 切换（exe 确认为「亚种编号 = 5」，见第 7 节），所以激昂金狮子 = 普通金狮子的招式库 + 激昂专属主控 + D0(5) 分支。

一轮决策从 `em023_00.node_000` 开始，选出一招后 `reset`：

 │   ├─ G102  反钩爪抓取（按 HP 概率，R6 冷却）

     ├─ target(3/4/55/12/14/11/0) 目标状态 → 对应处理并 reset
     ├─ 计数：G090 R12 · G091 R14 · G098 R10 · G100 R4 · G108 R1
     ├─ G245  高低差 >450：冲到 500 内出一招（不 reset）
     ├─ G093 / G092  抓取（R14≥5 30% / R15 必抓）
     ├─ G099  硬化特殊跳（R11）  ├─ G101 连发气弹（R5）  ├─ G109 近身特殊招（R2）
     ├─ G143  目标是随从猫 2D(1) → 另一套攻击表

**愤怒表 010~015 直接调用普通表 004~009**，所以愤怒本身不改变出招；只有超斗气硬化才换表。

## 3. 计数器（寄存器）

| 寄存器 | 含义 | 规则 |
|---|---|---|
| R12 | 硬化计数 | 愤怒且本次未硬化过时每轮 +1；每轮开头（计数前）检查，HP>75% ≥8、≤75% ≥6、≤50% ≥4、≤25% ≥2（任务 63149 ≥3，但该任务没有金狮子，不会触发）→ pump_up 并清零。进入愤怒时清零 |
| R14 / R15 | 抓取计数 / 待发 | R14 每轮 +1；≥5 后每轮 30% 正前方抓取；≥15 置 R15，下一轮必抓。**≥8、≥10 分支是死代码** |
| R10 / R11 | 硬化特殊跳计数 / 待发 | 硬化中每轮 +1；≥5 50%、≥6 75%、≥7 100% 置 R11 → 界王拳 |
| R4 / R5 | 连发气弹计数 / 待发 | 每轮 +1；≥4 10%、≥8 30%、≥12 100% 置 R5 → 雷球 |
| R1 / R2 | 近身计数 / 待发 | 1000 内每轮 +1；≥4 10%、≥10 30%、≥16 100% 置 R2 → 50% 前顶 / 50% 后跃+悠悠球 |
| R13 | 侧跳计数 | 2000 内每轮 +1；700 内 ≥3、700~2000 ≥2 → 侧跳/后跳 →（70% 小挠）→ 追加一招 |
| R6 | 反钩爪抓取冷却 | 抓过后每轮 +1；≥3 10%、≥7 20%、≥11 50%、≥15 100% 解除 |
| R8 | 前置检查令牌 | 换区、残血等上下文 +1；45() 为真时消耗 |
| R9 | 激光次数 | 激昂主控不读取（普通金狮子主控用它切表） |
| R3 | 领地争夺计数 | ≥6/≥10 时强制换区 |

「待发」模式：计数达到阈值时只置一个标志，**下一轮**才出招，所以这些特殊招总是出现在一轮的开头。

## 4. 关键结论

1. **超斗气硬化：愤怒后数轮必进，血越少越快。** 愤怒中、本次愤怒尚未硬化过（`102()`）时每轮 R12+1，HP>75% 先出满 8 轮招、≤75% 6 轮、≤50% 4 轮、≤25% 2 轮，下一轮开头 pump_up（`G089`）。exe 中硬化期间 `102()` 被锁存为假，**每次愤怒最多硬化一次**。
2. **愤怒不改变出招表**，只有硬化才换成 016~020 硬化表。
3. **超解（五向雷）是硬化专属**，也是硬化后最常见的招：硬化中任何距离每轮出现率 30%~37%（含追加），700 内与 2300 外排第一，1000~2300 仅次于飞拳。
4. **红手三连砸**只在 激昂 + 硬化 + 700 内：回手掏后必接（`G013`），王八拳后目标在背后半圈 70% 接（`G001`）。普通金狮子同位置是三连拳。
5. **抓取**：R14≥5 后每轮 30%，且目标须在 500~1400、正前方锥形内（600 内 ±30°、800 内 ±25°、1200 内 ±20°、1400 内 ±15°，`G094`）；R14 满 15 下一轮必抓。`G093` 先判 ≥5 再判 ≥8/≥10，**后两档是死代码**。
6. **每 2~3 轮必有一次侧跳回合**（R13，`G096`）：侧跳/后跳 → 70% 小挠（1200~1500 任意角度；550~1200 要求目标偏离正面 45° 以上）→ 按距离追加一招。
7. **体术后必有追加**：悠悠球、飞拳、小挠后进 `G059` 按距离再出一招；回旋/下压/掀地后接捶胸（破绽）。**雷击系放完就停**：激光、超解、横扫没有追加，雷球只在 1000 外 30% 接飞拳。
8. **被打出硬化时抓墙：100% 横扫激光。** `G104` 中 `2C(0,30)` / `2C(0,60)` 两个 30%/70% 分支在 exe 中恒为假（第 7 节），激昂个体实际 100% 出 `G106` 抓墙横扫激光。
9. **钩爪抓手臂**：按 HP 决定是否反钩爪抓取——>80% 60%、≤80% 30%、≤60% 80%、≤40% 50%、≤20% 30%，之后 R6 冷却。
10. **远距离先冲刺**：>2300 时冲到 500/700/1000/1500（10/10/20/60%），再侧跳并按新距离出招。**高低差 >450** 时 `G245` 冲到 500 内出一招但不 reset，同一轮还会继续选招（一轮两招）。
11. **激昂专属的计数机制**：正前方抓取 `G093`、连发气弹 R4/R5、近身特殊招 R1/R2 只在激昂主控中调用；普通金狮子主控则有激昂版没有的「激光后切表」（R9）。
12. **对空：只看高度差，不看猎人是不是在跳。** THK 没有「猎人在空中」条件；`vertical_distance_to_target` 是高度差的绝对值（exe：`function#F` 对 AI `+0x618` 取绝对值），猎人在上方也算。每轮 `G245`：高度差 >450（龙结晶之地区域 3 为 >400）→ 冲到 500 内 → 侧跳/后跳 + 追加一招，不 reset；抓取命中后被抓目标高度差 >500 → 落空；特殊地形 `G112` 高度差 >800 → 激光（疲劳时跳墙）。猎人攀墙/抓藤（`target(0)`，参数 2 = 1）或乘翼龙/滑索（`target(14)`）→ `G248`：1200 内按上下关系出跳上高处攻击（之后 75% 激光 / 25% 下压，疲劳时必下压）或跳下高处攻击。
13. **《你是黄金奖杯》（q66861）的 AI 与普通激昂相同**，区别只在任务数据：斗技场（st202）、历战标志 1（THK 不读）、能力档位 819（普通 485）、多人档位 211（普通 127），见 5.1 节。

### 5.1 任务《你是黄金奖杯》（q66861）与斗技场

任务数据用 Blowfish 解密后按 QuestDataDump 的 Iceborne 模板解析（`python tools/questdata.py 92`），激昂金狮子的能力档位是 `em_difficulty.dtt_dif` 的行号，每个字段取该行对应的一列：

| 51607 / 51623 / 66857 / 66863 | 永霜冻土（66863 为瘴气之谷） | 0 | 485 | 7.40 | 13.10 | 5.60 | 1.60 / 3.00 | 1.30 | 1.80 | 1.50 | 127（2.6 / 2.9） |

黄金奖杯相对普通激昂：体力 ×1.24、攻击 ×1.22、部位耐久 ×1.96、眩晕 ×1.92、异常 ×1.5、减气 ×1.39、骑乘 ×1.33。历战标志不影响能力（QuestDataDump 结论），激昂的 THK 也不读历战相关的 `B9()`。

斗技场（st202，Leviathon 称 `Challenge_Arena`）里 THK 的差别对所有在这里的激昂都一样：

- **目标丢失**（烟雾、躲藏，`em023_29`）：固定快速转身 + 55% 咆哮 / 35% 嗅探 / 10% 威吓；野外则按疲劳、目标状态、3500 内外分支。
- `em023_52`：在斗技场 / 特殊斗技场冲向固定点（area 64）。
- 怪物互斗（`G147~149`）的 R3 次数上限在两种斗技场里不生效（单怪任务用不到）。

## 8. 未解之谜

- 已在历战王冰呪龙的分析中确认：`2D(1)`（目标标志 bit14）= **目标是随从猫**，所以 `G161~166` 是对随从猫的攻击表。
- `self.target(N)` 是通用函数 0x2E「目标状态 N」：`target(0)`（参数 2 = 1）= 猎人攀墙/抓藤，`target(14)` = 猎人乘翼龙/滑索（定时状态），见第 7 节；`target(0)` 参数 2 ≠ 1 的分支与 11/12 未确认。
- `7F(1)/(4)` 推测为双臂、`7F(2)/(3)` 为其他部位，未逐一确认。
- 普通金狮子主控 `node_001` 调用 Global 中不存在的节点 401；激昂版改为抓取，但两者都没有节点调用它。
