# 激昂金狮子 Furious Rajang（em023_05）AI 解析

> 交互版（出招模拟器、扇区热力图、带中文注释的 THK 代码）：<https://mhwi.helsincy.com/#/em023_05>（或本地打开 `web/index.html`）。

## 1. 数据来源与方法

| 变化 | 说明 |
|---|---|

## 2. AI 文件结构

`em023.thklst`（05）共 72 个槽位，使用 34 个 THK：

| 上下文 | 文件 | 作用 |
|---|---|---|
| Combat_Main | **05/data/em023_00** | **激昂专属战斗主控**，22 个节点 |
| Global | 00/data/em023_55 | 招式库，262 个节点，**与普通金狮子共用** |
| Rage_Enter | em023_07 | 进入愤怒：清零硬化计数 R12，后跃 + 愤怒吼叫 |
| Combat_Critical_HP | em023_20 | 濒死：走向睡眠区域并睡眠（`dying_sleep` 参数激昂个体 90、普通 150，含义未确认） |
| Combat_Turf_War_A/B | em023_23 / em023_50 | 领地争夺 |
| Mount / Combat_Blinded / … | 其余 | 骑乘、闪光、换区等 |

Global 里所有「激昂版」招式都由 `function#D0(5)` 切换（exe 确认为「亚种编号 = 5」，见第 7 节），所以激昂金狮子 = 普通金狮子的招式库 + 激昂专属主控 + D0(5) 分支。

一轮决策从 `em023_00.node_000` 开始，选出一招后 `reset`：

```
node_000
 ├─ node_002 前置检查 A（45() 为真时需用掉 R8 令牌）
 │   ├─ G104  倒地回避成功 → 抓墙横扫气功炮 / 106() → 恢复
 │   ├─ G089  超斗气硬化判定（R12 达到 8/6/4/2）
 │   ├─ G102  反钩爪抓取（按 HP 概率，R6 冷却）
 │   ├─ G146  领地争夺 / 其他大型怪物
 │   └─ G237  选目标 / 泥浆 / 烟雾弹
 └─ node_003 前置检查 B + 主表
     ├─ target(3/4/55/12/14/11/0) 特殊地形 → 对应处理并 reset
     ├─ 计数：G090 R12 · G091 R14 · G098 R10 · G100 R4 · G108 R1
     ├─ G245  高低差 >450：冲到 500 内出一招（不 reset）
     ├─ G093 / G092  抓取（R14≥5 30% / R15 必抓）
     ├─ G099  硬化特殊跳（R11）  ├─ G101 连发气弹（R5）  ├─ G109 近身特殊招（R2）
     ├─ G143  2D(1) → 另一套攻击表
     ├─ G096  侧跳回合（R13）
     └─ 主表：距离 500/700/1000/1500/2300 × 硬化(016~021)/愤怒(010~015)/普通(004~009)
```

**愤怒表 010~015 直接调用普通表 004~009**，所以愤怒本身不改变出招；只有超斗气硬化才换表。

## 3. 计数器（寄存器）

| 寄存器 | 含义 | 规则 |
|---|---|---|
| R12 | 硬化计数 | 愤怒且本次未硬化过时每轮 +1；每轮开头（计数前）检查，HP>75% ≥8、≤75% ≥6、≤50% ≥4、≤25% ≥2（任务 63149 ≥3）→ pump_up 并清零。进入愤怒时清零 |
| R14 / R15 | 抓取计数 / 待发 | R14 每轮 +1；≥5 后每轮 30% 正前方抓取；≥15 置 R15，下一轮必抓。**≥8、≥10 分支是死代码** |
| R10 / R11 | 硬化特殊跳计数 / 待发 | 硬化中每轮 +1；≥5 50%、≥6 75%、≥7 100% 置 R11 → 大跳跃强袭 |
| R4 / R5 | 连发气弹计数 / 待发 | 每轮 +1；≥4 10%、≥8 30%、≥12 100% 置 R5 → 跳跃连发气弹 |
| R1 / R2 | 近身计数 / 待发 | 1000 内每轮 +1；≥4 10%、≥10 30%、≥16 100% 置 R2 → 50% 猛冲 / 50% 后跃+翻滚跳砸 |
| R13 | 侧跳计数 | 2000 内每轮 +1；700 内 ≥3、700~2000 ≥2 → 侧跳/后踢 →（70% 头槌）→ 追加一招 |
| R6 | 反钩爪抓取冷却 | 抓过后每轮 +1；≥3 10%、≥7 20%、≥11 50%、≥15 100% 解除 |
| R8 | 前置检查令牌 | 换区、残血等上下文 +1；45() 为真时消耗 |
| R9 | 气功炮次数 | 激昂主控不读取（普通金狮子主控用它切表） |
| R3 | 领地争夺计数 | ≥6/≥10 时强制换区 |

「待发」模式：计数达到阈值时只置一个标志，**下一轮**才出招，所以这些特殊招总是出现在一轮的开头。

## 4. 关键结论

1. **超斗气硬化：愤怒后数轮必进，血越少越快。** 愤怒中、本次愤怒尚未硬化过（`102()`）时每轮 R12+1，HP>75% 先出满 8 轮招、≤75% 6 轮、≤50% 4 轮、≤25% 2 轮，下一轮开头 pump_up（`G089`）。exe 中硬化期间 `102()` 被锁存为假，**每次愤怒最多硬化一次**。
2. **愤怒不改变出招表**，只有硬化才换成 016~020 硬化表。
3. **五向雷（游民星空攻略称「超解」）是硬化专属**，也是硬化后最常见的招：硬化中任何距离每轮出现率 30%~37%（含追加），700 内与 2300 外排第一，1000~2300 仅次于飞扑锤击。
4. **四连拳·雷断层**只在 激昂 + 硬化 + 700 内：转身勾拳后必接（`G013`），摇摆冲拳后目标在背后半圈 70% 接（`G001`）。普通金狮子同位置是三连拳。
5. **抓取**：R14≥5 后每轮 30%，且目标须在 500~1400、正前方锥形内（600 内 ±30°、800 内 ±25°、1200 内 ±20°、1400 内 ±15°，`G094`）；R14 满 15 下一轮必抓。`G093` 先判 ≥5 再判 ≥8/≥10，**后两档是死代码**。
6. **每 2~3 轮必有一次侧跳回合**（R13，`G096`）：侧跳/后踢 → 70% 头槌（1200~1500 任意角度；550~1200 要求目标偏离正面 45° 以上）→ 按距离追加一招。
7. **体术后必有追加**：翻滚跳砸、飞扑锤击、头槌后进 `G059` 按距离再出一招；回旋/泰山压顶/掀地后接捶胸（破绽）。**雷击系放完就停**：气功炮、五向雷、横扫没有追加，跳跃连发气弹只在 1000 外 30% 接飞扑。
8. **被打出硬化时抓墙：100% 横扫气功炮。** `G104` 中 `2C(0,30)` / `2C(0,60)` 两个 30%/70% 分支在 exe 中恒为假（第 7 节），激昂个体实际 100% 出 `G106` 抓墙横扫气功炮。
9. **钩爪抓手臂**：按 HP 决定是否反钩爪抓取——>80% 60%、≤80% 30%、≤60% 80%、≤40% 50%、≤20% 30%，之后 R6 冷却。
10. **远距离先冲刺**：>2300 时冲到 500/700/1000/1500（10/10/20/60%），再侧跳并按新距离出招。**高低差 >450** 时 `G245` 冲到 500 内出一招但不 reset，同一轮还会继续选招（一轮两招）。
11. **激昂专属的计数机制**：正前方抓取 `G093`、连发气弹 R4/R5、近身特殊招 R1/R2 只在激昂主控中调用；普通金狮子主控则有激昂版没有的「气功炮后切表」（R9）。

## 7. exe 逆向：金狮子专属函数

方法同黑龙（第 7 节）：游戏运行时只读导出内存镜像，Capstone 反汇编，类名来自 MHW-DTI-Dumps。地址只适用于 build 421810。

| 步骤 | 地址 | 内容 |
|---|---|---|
| `uEm023` 构造 | `0x1404ba570` | 由 DTI 的 newInstance（`0x1404b5bb0`）以内部编号 0x5b（91 = 金狮子）调用；基类构造 `0x141ca1f00` 后写入虚表 `0x142f8fac8` |
| 专属条件处理 | `0x1404bb140`（虚表 `+0x8d8`） | `switch (functionType - 0x101)`，0x101~0x109 共 9 个 case |
| 硬化置位 | `0x1404bae10`（虚表 `+0xc28`） | 写 `+0x20a90`；置 1 时要求 `+0x1be44 == 1`（愤怒中） |
| 硬化锁存 | `0x1404bd440`（每帧） | `+0x20a98==0 && +0x20a90 && 愤怒` 时把 `+0x20a98` 置 1 |
| 硬化结束 | `0x1404bbd90`、`0x1404be110`（虚表 `+0xa20`） | 调用 `+0xc28(0)` 清硬化，并清 `+0x20a98` |

| 函数 | exe 中的逻辑 | THK 里的含义 |
|---|---|---|
| `101()` | `return this[+0x20a90]` | **超斗气硬化中** |
| `102()` | `return this[+0x20a98] == 0` | **本次愤怒尚未硬化过** |
| `103()` | 有被抓目标时调用抓取处理并返回真 | 抓取命中处理（副作用） |
| `104()` | 当前动作 == 200 `TO_DAMAGE_DOWN_AVOID_SUCCESS` | 刚倒地回避成功（抓墙） |
| `105()` | 目标为怪物且对方的某状态成立 | 领地争夺用 |
| `106()` | 虚表 `+0xc68` | 需要恢复（出 refresh） |
| `107()` | `+0x20ab9` 为真则清零并返回真 | 一次性事件（只用于普通金狮子剧情任务） |
| `109(p1,p2)` | 遍历被抓目标以外、距离 p1 内的猎人 | 硬化抓取终结前调用，推测与零距离气功炮波及有关 |

通用函数（所有怪物共用的分发 `0x14133478e`）：

| 函数 | exe 中的逻辑 | 结论 |
|---|---|---|
| `D0(p)` | `monster[+0x888] == p`（`0x141badf70`） | 亚种编号。全部怪物 THK 中只有金狮子与黑狼鸟（em018_05 伤痕黑狼鸟）用到 `D0(5)`，两者都有 05 号亚种 |
| `2D(p)` | 当前目标对象 `+0x60` 标志位：p=0 → bit0，p=1 → bit14，p=2 → bit1 | `2D()` 推测为「目标是猎人」，`2D(2)` 为「目标是怪物」 |
| `2C(p1,p2)` | 只有 p1 == 2 时才比较数值，否则直接返回假 | `G104` 的 `2C(0,30)`、`2C(0,60)` **恒为假** |
| `45()` | 当前动作的属性位与全局掩码 | 为真时跳过每轮前置检查（需 R8 令牌） |

## 8. 未解之谜

- `2D(1)`（目标标志 bit14）为真时整套攻击表换成 `G161~166`，未确认是什么目标。
- `self.target(N)` 的 0/11/12/14 等类型（推测为高低差/无法到达的地形）。
- `7F(1)/(4)` 推测为双臂、`7F(2)/(3)` 为其他部位，未逐一确认。
- 普通金狮子主控 `node_001` 调用 Global 中不存在的节点 401；激昂版改为抓取，但两者都没有节点调用它。
