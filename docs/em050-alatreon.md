```bash
node scripts/sim.js em050_00 elem=1 dist=800 angle=0                 # 炎活性，正面 800
node scripts/sim.js em050_00 elem=3 R1=1 R2=5 dist=800 angle=0       # 龙活性，已起飞过

node scripts/sim.js em050_00 elem=1 hp=50 R0=3                        # 第一周期 HP≤55%，第 4 轮转龙
```

**记号约定**（THK 的比较方式已在 exe 中核对，见 `0x1413346a0` 条件分发）：

- 距离：`distance_*().leq(N)` 是 ≤N（含 N），`.gt(N)` 是 >N（不含 N）。文中「≤1000」「>5000」照此理解；「>1000 且 ≤5000」表示两档之间——THK 按 ≤A、≤B 依次判断，所以区间都是左开右闭。垂直距离同样是 ≤ / >（取绝对值）。
- 角度：从正面顺时针计；`angle_2d_cw_between(a,b)` 两端都含（`0x14132bb00`），跨 0° 时为 ≥a 或 ≤b。
- 血量：`hp_percent().leq(N)` 先算 当前 ÷ 最大 × 100，再**截断取整**（`cvttss2si`）后与 N 比较。所以「HP≤49%」即实际血量 <50%，「HP>75%」即实际 ≥76%。按目标血量判断的函数（如 `103/10E/113(3,N)`）也是取整后的整数比较（`0x141338ee0`）。
- 计数器：整数比较，按文中写的符号。
- 例外：空中滑翔「停在离目标 200 处」是滑翔动作的参数，不是判断条件。

## 3. 属性与周期

属性存在 `uEm050 +0x208e0`（0 无活性、1 炎、2 冰、3 龙）。**没有任何计时器**：属性、起降、审判全部由寄存器计「轮」，一轮 = 主控一次决策（普通攻击 + 属性大招，通常 1~3 招）。硬直、倒地、属性压制期间主控不跑，轮数也不增加——这就是社区观察到「计时暂停」「硬直推迟起飞」的原因。

| 周期 | 炎 / 冰活性 | 龙活性 |
|---|---|---|
| 第 1 个（审判 0 次） | 11 轮 → 起飞 → 空中 5 轮 → 降落 → 2 轮 → 转龙 | 3 轮 → 起飞 → 空中 5 轮 → 降落 → 10 轮 → 审判 |
| 第 2 个（审判 1 次） | 11 轮 → 起飞 → 空中 3 轮 → 降落 → 转龙 | 3 轮 → 起飞 → 空中 3 轮 → 降落 → 8 轮 → 审判 |
| 第 3 个起 | 10 轮 → 转龙（不再起飞） | 3 轮 → 起飞 → 空中 5 轮 → 降落 → 6 轮 → 审判 |

（起飞、降落、转龙、审判本身各占一轮。）

第一周期的血量提前：

- 炎/冰活性 HP≤55%：地面满 4 轮就转龙；若已在空中，空中第 2 轮起直接降落。在第 12 轮地面之前打到 55% 就能跳过第一次起飞。
- 龙活性 HP≤20%：地面满 9 轮就审判（仍会在第 4 轮先起飞一次），空中第 2 轮起直接降落。
- 审判过一次后，这些血量条件全部失效。

审判去向（`G197`）：本次龙活性破过角（`102()`）→ 回到本周期原来的属性；没破角 → 换到另一个属性。龙活性的起降招与空中普通攻击都使用「另一个属性」那一套（由炎转来的龙用寒岭天冰起飞、空中龙车降落），恰好预告了不破角时审判后的属性。

## 5. 关键结论

1. **没有计时器**：属性只由动作（转龙、审判）和属性压制倒地改写（exe 属性设置函数 `0x1404c6450` 的调用者全部是动作代码），切换/起降/审判全部按轮数。
2. **周期轮数**见第 3 节；第三周期起炎/冰活性不再起飞（R0 满 11 先于 R2 满 12）。
3. **血量只在第一次审判前有用**：炎/冰 HP≤55% 满 4 轮转龙，龙 HP≤20% 满 9 轮审判。
4. **破角决定审判去向**；`102()` = 本次龙活性破过角（exe：部位破坏回调 `0x1404c8530` 置 `+0x208f8`，审判后清零）。
5. **龙活性的起降招与空中普通攻击使用另一属性的版本**，预告不破角时的下一个属性。
6. **地面一轮 = 普通攻击 + 属性大招**；R8/R9 防止同长度普通攻击、同类大招连续出现；每 4~5 轮必有一次长连段。
7. **愤怒只改三处**：长连段提前一轮、跟踪雷 2→3 道、空中叩击 2→3 下。龙车次数与愤怒无关；空中长短连段节奏愤怒与否两支完全相同。
8. **血量越低大范围招越多**：爆炎灭碎阵（>1400 且 ≤4000）、三向冰锥（>1400 且 ≤3000）、五排雷只在 HP≤75% 后出现；HP≤40% 时 ≤900 的炎大招全是地爆三星。
9. **龙活性起飞后大招固定轮换** 龙 → 冰 → 雷 → 炎（`G087`），不再随机；普通攻击换成混合表。
10. **空中每轮先滑翔到离目标 200 处**（`G371`），猎人不动时只会出 ≤500 的空中招；空中叩击、空中龙魂释放、机关炮要猎人在滑翔后离开 >500 才会出现。
11. **炎、冰活性在空中都会用水招**（照星·崩流、沧海·螺旋、月华·雹雨等）；地面上炎活性不出冰招、冰活性不出炎招。
12. **钩爪挂身时龙大招必出拜年**，空中必出空中叩击。
13. **不换目标再来一轮**：目标倒地 / 被压制 / HP≤40% 时每轮末 50%，再来的那一轮照常计数。
14. **死代码**：R11、`101(4)` 后的两个 35% 分支、73 个未调用的 Global 节点（龙车起飞、三连火球、一次性威吓等）。
15. **终结审判期间打不死（游戏实测，exe 印证）**：照常掉血，但血量最低锁在 1。THK 里没有这一点：审判动作每帧给怪物置「不死」状态位（任务指令 `ForceNoDeathSet_em` 同一位），受伤结算把会低于 1 的血量改成 1；状态位每帧清空，动作结束即失效。转炎/转冰/转龙、绝对熔点领域、寒岭天冰、审判前冲向入口的不可打断冲刺（`G198`）同样锁血。
