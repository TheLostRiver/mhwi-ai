# 雷狼龙 Zinogre（em057_00）AI 解析

> 交互版（出招模拟器、扇区热力图、带中文注释的 THK 代码）：<https://mhwi.helsincy.com/#/em057_00>（或本地打开 `web/index.html`）。

## 1. 数据来源与方法

工具链同黑龙（见 [em013-fatalis.md](em013-fatalis.md) 第 1 节）：`em057/00/data` 下 35 个 THK，441 个节点（战斗主控可达 186 个），逐行往返一致、随机权重和均为 100。

THK 只决定「出什么招」，**电量（蓄电）不在 THK 里**：它由通用组件 `cpEmBarrierParam` 管理，数值来自两处游戏数据：

- `em057.actp2`：每个动作的 `mIncBarrierValue` / `mDecBarrierValue`。本次新增 `tools/actp2.py` 读取（动作对象以 `JAMCRC("ACTION::<名字>")` 标识，字段值写在字段名之前）。
- `em057.dtt_unq`（`nEmDtTune::cEmUniqueEm057`）：开头是电量层级表、倍率和开场电量。

社区资料：腾讯新闻 爱游戏的Solay《雷狼龙超带电机制与连段解析》（2020-07-22），游民星空 SweetPotatoH「超带电状态」（2020-05-17，转自 NGA）。两者的说法在第 7 节逐条对照。

```bash
node scripts/sim.js em057_00 dist=600 angle=0                      # 未超带电，正面 600
node scripts/sim.js em057_00 dist=700 angle=0 charged=true enraged=true
node scripts/sim.js em057_00 dist=1500 angle=0 postCharge=true     # 刚蓄电的下一轮
node scripts/sim.js em057_00 dist=700 angle=0 'flag:self.target.helpless_0()=1'
python tools/actp2.py extracted/em/em057/00/data/em057.actp2 94 mIncBarrierValue mDecBarrierValue
```

**记号约定**（THK 的比较方式已在 exe 中核对，见 `0x1413346a0` 条件分发）：

- 距离：`distance_*().leq(N)` 是 ≤N（含 N），`.gt(N)` 是 >N（不含 N）。文中「≤1000」「>5000」照此理解；「>1000 且 ≤5000」表示两档之间——THK 按 ≤A、≤B 依次判断，所以区间都是左开右闭。垂直距离同样是 ≤ / >（取绝对值）。
- 角度：从正面顺时针计；`angle_2d_cw_between(a,b)` 两端都含（`0x14132bb00`），跨 0° 时为 ≥a 或 ≤b。
- 血量：`hp_percent().leq(N)` 先算 当前 ÷ 最大 × 100，再**截断取整**（`cvttss2si`）后与 N 比较。所以「HP≤49%」即实际血量 <50%，「HP>75%」即实际 ≥76%。按目标血量判断的函数（如 `103/10E/113(3,N)`）也是取整后的整数比较（`0x141338ee0`）。
- 计数器：整数比较，按文中写的符号。
- 例外：半血蓄电覆盖表（`0x140a27ae0`）直接比较实际血量的浮点值，0%~50.0% 两端都含，不取整。

## 3. 电量机制

| 项目 | 数值 | 来源 |
|---|---|---|
| 电量范围 | 0 ~ 100，加减后截断 | exe `cpEmBarrierParam` 构造：上限 `+0x1a0` = 100 |
| 层级阈值 | [0, 99, 100]：层级 = 严格小于电量的阈值个数 | `em057.dtt_unq` 开头 |
| 进入 / 解除 | 层级到最高（电量 100）进入超带电；层级回到 0（电量 0）解除 | exe 层级回调 `0x140a26500` |
| 血量倍率 | 电量组件自带的血量倍率：阈值字段 = 0（关闭） | `em057.dtt_unq` 开头 |
| 半血蓄电覆盖表 | 动作开始时按（当前动作, 血量%）查表改写蓄电量：血量 0~50% 时 51/52 → 35、53/109 → 75 | `dtt_unq +0xb8`，exe `0x140a27ae0` |
| 开场电量 | 按 (权重, 电量) 随机：普通 (100, 0)；`em057_uqe` 变体 (100, 100)；B9 为真时直接设为上限 | `dtt_unq` + exe `0x140a27f10` |

各动作的电量增减（`em057.actp2`，未列出的动作为 0）：

| 动作 | 增减 | 说明 |
|---|---|---|
| LIGHTNING_CHARGE_MIN 小蓄电 | +25（血量 ≤50% +35） | 龙车/后跳后 85%、远距离主表 |
| SHORT_LIGHTNING_CHARGE 倒地追击蓄电 | +25（≤50% +35） | 猎人倒地时（未超带电、不疲劳） |
| LIGHTNING_CHARGE_MAX 大蓄电 | +50（≤50% +75） | 只在连段末尾（前顶 → 后跳 → 飞扑 → 大蓄电） |
| CATCH_SUCCESS_LIGHTNING_END 捕食成功蓄电 | +50（≤50% +75） | |
| DAMAGE_TRAP_PARALYSE 麻痹陷阱 | **+100** | 直接充满 |
| CHARGE_TRANS 进电演出 | +100 | |
| DAMAGE_LOW / DAMAGE_HIGH 小 / 大硬直 | −5 / −15 | |
| DAMAGE_DOWN、DROP_TO_GROUND、TRAP_FALL、STUN、TAIL_BREAK、CLAW_GRAB_HIT_WALL、DRAGON_CANNON、FLASH_FLY、RIDE_DOWN 等 | **−35** | 倒地类硬直 |
| DAMAGE_ROCK 落石 | −70 | |
| DAMAGE_HIGH_LIGHTNING_RELEASE / DROP_TO_GROUND_LIGHTNING_RELEASE 破电硬直、WATER_SLIDE_FALL | −100 | |
| MARKING 做记号 | −10 | 非战斗 |

由此：

- 从 0 到超带电：小蓄电 ×4、小 ×2 + 大 ×1、大 ×2、或一次麻痹陷阱；血量 ≤50% 时小蓄电 ×3（105）、小 + 大（110）、或大 ×2。多出的部分截断。
- 超带电期间电量只会减少：三次倒地类硬直（3 × 35）就能把电量打空，不一定要靠破电硬直。
- 「半血以下 3 层就进入超带电」**成立**：层级阈值固定、电量组件的血量倍率也是关闭的，但雷狼龙自己的覆盖表在血量 ≤50% 时把小蓄电改成 +35。本文早先判为不成立是漏看了这张表。

## 5. 关键结论

1. **电量满 100 才超带电，半血以下蓄电更多**（第 3 节）：血量 ≤50% 时小蓄电 +35、大蓄电 +75，小蓄电 3 次即超带电；加电量截断，没有「留到下一次」。
2. **前顶连段**：未超带电、不疲劳、≤800 正面每轮 **40%**（`node_023` → `G122`）。前顶结束后才判定方位：正面 后跳 → 飞扑 → **大蓄电 +50**，身后 翻身甩尾，侧面 铁山靠。腾讯所说的「快速蓄电」就是这个大蓄电。
3. **猎人倒地必定蓄电**：`node_011` 在本轮攻击后检查猎人是否倒地，未超带电且不疲劳时 **100%** 走 `node_013~015`，≤3000 全部是倒地追击蓄电（+25）。超带电时则 50% 追加一次攻击。
4. **刚蓄电的下一轮不会再蓄电**：exe 确认动作 51/52/53/109（短/小/大蓄电、捕食成功蓄电）执行时置 `10A`。下一轮未超带电的主表改用不含蓄电的前半张表并清除标记，例如 >1000 且 ≤3000 的蓄电概率从 52% 变为 0，改为 60% 飞扑。前顶连段和倒地追击蓄电不受影响。
5. **龙车 / 后跳之后 85% 小蓄电**（`G101`、`G117`）。另 15% 按距离追加：≤1000 B9（推测为历战个体）出前顶连段、否则重拳；≤3000 飞扑；更远小蓄电。
6. **连续灌篮**：超带电 ≤3000 先判定 `node_026`：怒后 **25%**、怒前 **5%**（雷狼龙 HP≤40% 时 30% / 10%），打出后冷却一轮。
7. **受击反击之后必接追击**：exe 确认动作 121/123/129/131（DAMAGE_COUNTER_ATTACK 系列）开始时置 `105`。超带电且愤怒时，下一轮开头 `G136` **100%** 走 `G139` 追击连段。
8. **怒前的背砸只打倒地的猎人**：超带电怒前的背砸只出现在猎人倒地时的表里（`node_048` 25%、`node_055` 60%、倒地追击 `node_017/018`）。怒后的背砸出现在连段收尾。
9. **开场电量**：普通个体 0；`B9` 为真时初始化直接满电，即开场超带电（exe `0x140a27f10`）。《再会了，雷狼龙》换用的数据开场电量也是 100（5.1 节）。
13. **《再会了，雷狼龙》（q66865）与普通雷狼龙是同一套 AI**，差别全在 exe 按任务号换用的 `em057_uqe` 数据：开场即超带电、每次蓄电 +100、破电更容易、肉质与愤怒参数不同，见 5.1 节。
10. **疲劳**：不出前顶连段、不出倒地追击蓄电，每 5 轮喘一次。
11. **随从猫是另一套表**（`node_061` → 062~076）：没有前顶连段、连续灌篮与倒地追击。
12. **未使用的节点**：主控 `node_031/034/037`；Global `G102/104`（与 101/103 相同）、`G123/127/129/137/138` 连段没有被引用。`G072 charge_trans` 只由 THK_60 调用。
